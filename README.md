# AI Karaoke Studio v0.2 (Russian Edition) 🎤

Автоматическая локальная студия для создания караоке-видео на Python (Apple Silicon M-серия / Metal, Demucs, Whisper RU, Wav2Vec2 CTC, FFmpeg).

## Что нового в v0.2
- 🇷🇺 **Заточено под русский язык и кириллицу:**
  - Язык по умолчанию — `ru`.
  - Поддержка лучших моделей для русского: `large-v3-turbo` (дефолт), `bond005/whisper-podlodka-turbo`, `antony66/whisper-large-v3-russian`, `large-v3`.
  - Опциональное побуквенное кириллическое выравнивание через `Wav2Vec2-Russian CTC` (`--ctc-align`).
  - Калибровка начала фраз по реальной громкости вокала (`Vocal RMS Energy Gate`) и защита от «схлопнутых» слов (`\kf2`) с распределением по русским слогам.
  - Запрет на «висячие» предлоги и союзы в конце строки (`в`, `на`, `с`, `и`, `а`, `не` и др.).
- ✏️ **Интерактивный Редактор текста и таймингов в Web UI:**
  - Исправляй любые слова, меняй таймкоды `[ММ:СС.сс -> ММ:СС.сс]` или дели строки клавишей `Enter`.
  - Кнопка **«🔄 Пересобрать видео»** пересобирает ролик без повторного запуска нейросетей. Время зависит от длительности видео, эффектов и оборудования.
  - Возможность вставить готовый текст песни из интернета заранее.
- 🎙️ **Подмес вокала (Guide Vocal):**
  - Настраиваемый уровень оригинального вокала в минусовке (по умолчанию `0%`, от `0%` до `100%`), чтобы легко попадать в бит и сложные вступления.
- 📺 **3 или 4 строки на экране + отсчет `● ● ●`:**
  - Весь куплет (3 или 4 строки) появляется на экране заранее: пока поёшь текущую строку, всегда видишь следующие 2–3 строки вперёд.
  - Визуальный отсчет `●  ●  ●` за 3 секунды до вступления после проигрышей.

## Использование

### 1. Веб-интерфейс (Караоке-студия)
```bash
~/.local/bin/uv run karaoke-ui
```
Открой в браузере: `http://127.0.0.1:7860`

### 2. Через командную строку (CLI)
```bash
# Базовый запуск (4 строки, 0% вокал, язык ru, модель large-v3-turbo)
~/.local/bin/uv run karaoke song.mp3

# Со своим текстом песни и 15% громкостью вокала-подсказки
~/.local/bin/uv run karaoke song.mp3 --lyrics-file lyrics.txt --vocal-volume 0.15 --lines 4

# С русской fine-tune моделью и побуквенным CTC-выравниванием
~/.local/bin/uv run karaoke song.mp3 -m bond005/whisper-podlodka-turbo --ctc-align
```


### 3. Караоке поверх своего видео

В веб-интерфейсе загрузите MP4, MOV, MKV, WebM, AVI или M4V в поле
«Трек: аудио или видео». Программа извлечёт звук, подготовит минусовку и
наложит текст на движущийся оригинал. Галочка скачивания видео с YouTube
для локального файла не нужна. После правок текста нажмите «Пересобрать видео»:
исходный клип и уже подготовленные дорожки используются повторно.

```bash
uv run karaoke clip.mp4 --output-dir ./output
# Отдельный видеофон для аудиотрека (звук фона не используется):
uv run karaoke song.mp3 --bg background.m4v
```

Для видеоисточника песни нужна аудиодорожка; отдельный видеофон может быть
без звука. Нужны FFmpeg с libass и ffprobe. Выходной формат — H.264/AAC MP4,
1920×1080, 30 fps. Видео масштабируется с обрезкой краёв до 16:9.
Короткий фон повторяется, длинный обрезается; длительность результата
ограничена подготовленной аудиодорожкой. Звук исходного клипа заменяется
минусовкой с выбранной долей вокала.

Для пяти минут в Balanced ориентир размера — около 167 МБ; реальный размер
зависит от кодека, содержимого и пресета. Промежуточная перекодированная
копия видео не создаётся. Временная загрузка исходника сохраняется в проекте
без перекодирования, WAV/stems остаются для быстрой пересборки. Рендер
записывает временный MP4 и заменяет готовый файл только после успеха;
ошибка или отмена сохраняет предыдущий результат.


### Прогресс рендера и остановка

В финальном этапе полоса показывает процент **самого рендера** от 0 до 100,
а не остаётся на 90% всей обработки. Пример статуса:
`Рендер 42% · 01:28 / 03:31 · кадр 2640 · 150 fps · 5.00× · прошло 00:18 · осталось ≈ 00:24 · 40 МБ`.
Данные обновляются по фактическому выводу FFmpeg примерно каждые полсекунды.
Оценка оставшегося времени меняется вместе со скоростью кодирования.
До первых кадров отображается «расчёт…»; после кодирования отдельно идёт
проверка и сохранение MP4. 100% появляется после успешной проверки результата.

Кроме ограничения длительности действуют ограничение числа кадров и предельный
размер файла, рассчитанный по длительности и максимальному битрейту пресета.
Если бюджет превышен, обработка завершается ошибкой, временный MP4 удаляется,
предыдущая удачная сборка сохраняется. Кнопка остановки работает сразу,
в том числе во время финального рендера. Генерация и пересборка выполняются
по очереди, чтобы два процесса не записывали один проект одновременно.

После изменения кода перезапустите сервер и обновите страницу браузера:
обычный запуск `run_ui.py` не перечитывает Python-модули автоматически.
Актуальная версия интерфейса — **v0.3.9**.

### Тайминги повторяющихся припевов

Готовый текст сопоставляется с распознанными словами последовательно, с учётом
всей песни. Если в готовом тексте слишком много повторов для найденных временных
интервалов, анализ использует распознанный текст и показывает предупреждение.
При редактировании слова остаются внутри заданного интервала строки; повторная
пересборка сохраняет тайминги неизменённых строк. Обратные интервалы и пересечения
соседних слов более 0,01 секунды отклоняются до рендера с указанием проблемной строки.

### Настройки студии

В разделе «Источники» выберите один аудио- или видеофайл либо вставьте ссылку.
Загруженный файл имеет приоритет над ссылкой. Оформление и начальные эффекты
настраиваются под плеером: «Эффекты и текст», «Фон», «Звук и экспорт».
При загрузке фоновой картинки появляется предпросмотр; удаление файла очищает его.
Базовый подмес вокала в итоговое видео по умолчанию равен 0%. Живой подмес
для прослушивания регулируется отдельно и не изменяет готовый файл.
