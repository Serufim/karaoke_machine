# AI Karaoke Studio 🎤 (v0.5.2)

**AI Karaoke Studio** — это профессиональное автономное приложение для создания караоке-видео студийного качества с полной локальной обработкой нейросетями (разделение вокала Demucs, транскрипция Whisper, побуквенное кириллическое выравнивание Wav2Vec2 CTC, интерактивный 3-дорожечный таймлайн и рендеринг в Full HD 1080p).

Оптимизировано для работы на **Apple Silicon (M1/M2/M3/M4, Metal/MPS)** и **NVIDIA GPU (CUDA)**, а также поддерживает режим процессора (CPU).

---

## 🚀 Что нового в v0.5.2

* 🛡️ **Интеллектуальный Text Sanitizer:** автоматическая очистка текстов от водяных знаков сайтов-агрегаторов (`Источник: txtsong.ru`, `genius.com`, доменных ссылок), структурных меток (`[Куплет 1]`, `(Припев)`, `Куплет:`, `Chorus:`) и меток повторов (`(х2)`, `[x3]`, `2 раза`). Больше никаких сбоев из-за скопированного с сайтов мусора.
* ⚡ **Density & Sanity Guard (Защита от сжатия в кашу):** отбрасывание ложных одиночных якорей при неестественной плотности слогов ($> 8$–$10$ слогов/сек). Слова больше не сжимаются в долю секунды на старте трека, а длинные инструментальные интро сохраняются идеально.
* 🎯 **Prompted Slice-Refinement (Локальный дожим вокала):** если в треке есть пропуск распознавания, но RMS-анализ вокала видит активное пение, алгоритм автоматически вырезает фрагмент и точечно распознает его с текстовой подсказкой (`initial_prompt`).
* 🎧 **DJ Master Pack Export:** экспорт в форматы профессиональных караоке-плееров — `.KFN` (KaraFun / EnCore!), `MP3+G` (.cdg + .mp3 для VirtualDJ / OpenKJ), Enhanced `.LRC` и UltraStar `.TXT` с питч-анализом нот.
* 🎵 **Dual-Audio MP4:** две переключаемые аудиодорожки в одном Full HD MP4 контейнере (Дорожка 1 = чистый минус, Дорожка 2 = оригинальный вокал для подсказки).
* ✂️ **Хирургический Slice Editor:** возможность точечно выделить в таймлайне проблемный фрагмент (от 0.5 с) и мгновенно перевыровнять тайминги или слоги без повторной пересборки всей песни.

## ⚡ Быстрый старт и установка

### Вариант 1. Готовые сборки (Релизы)

* 🍏 **macOS:** Скачайте `AI_Karaoke_Studio_macOS.dmg` из [Releases](https://github.com/Serufim/karaoke_machine/releases), откройте и перетащите в папку «Программы» (`Applications`).
* 🪟 **Windows:** Скачайте `AIKaraokeStudio-Setup.exe` (инсталлятор) или `AIKaraokeStudio-Windows-Portable.zip` из [Releases](https://github.com/Serufim/karaoke_machine/releases).

---

### Вариант 2. Запуск из исходного кода (Python 3.11)

Рекомендуемый менеджер окружения — [`uv`](https://astral.sh/uv):

```bash
# Клонирование репозитория
git clone https://github.com/Serufim/karaoke_machine.git
cd karaoke_machine

# Установка зависимостей
uv sync

# Запуск десктопной студии (Vue 3 + FastAPI, адрес http://127.0.0.1:7860)
uv run python run_ui.py
```

*Для классического интерфейса Gradio:*
```bash
uv run python run_ui.py --gradio
```

*Запуск из командной строки (CLI):*
```bash
uv run python -m karaoke.cli "song.mp3" --reference-lyrics "lyrics.txt"
```

## 📖 Что делать: пошаговый гайд от трека до готового клипа

1. **Создайте проект:**
   - Вставьте ссылку на YouTube или перетащите локальный аудиофайл (`.mp3`, `.wav`, `.flac`, `.m4a`).
   - При желании вставьте текст песни (можно прямо со страницы текста в браузере — Text Sanitizer сам очистит все копирайты и структуру).
   - Нажмите кнопку **«Создать караоке»**.

2. **Отредактируйте текст и тайминги (при необходимости):**
   - Нажмите на строку в таймлайне или текстовом редакторе, чтобы прослушать изолированный кусок.
   - Для точечной правки отдельной строки используйте **Slice Editor** или перетаскивайте границы фраз прямо на таймлайне.

3. **Настройте визуальный стиль и вокал:**
   - Выберите цветовую палитру суфлера: `gold_neon`, `cyan`, `magenta`, `lime`, `white` или адаптивный Ambilight под обложку.
   - Задайте эффект частиц: `sparkles_pulse` (пульсирующие искры), `neon_matrix` или `fire_particles`.
   - Отрегулируйте громкость бэк-вокала (0–100%) или нарисуйте кривую автоматизации.

4. **Экспорт:**
   - Нажмите **«Пересобрать видео»** — Full HD клип будет готов за считанные секунды без повторного прогона нейросетей.
   - Скачайте готовый `.mp4` с двумя дорожками или архив **DJ Master Pack** для профессиональных караоке-систем.

## 🎛️ Полный гайд по параметрам генерации

При создании проекта или по кнопке **«Параметры генерации»** вам доступен гибкий набор настроек нейросетей:

| Параметр | Рекомендуемое значение | Описание |
| :--- | :--- | :--- |
| **Whisper Model** | `large-v3-turbo` | В 5 раз быстрее базовой large-v3 при высочайшей точности на русском языке, песнях и рэпе. |
| **Demucs Model** | `htdemucs_ft` | 4-кратный fine-tuned ансамбль для кристального разделения вокала без артефактов в инструментале. |
| **VAD Filter** | `auditok` | Энергетический VAD. Отсекает инструментальные интро и паузы, защищая от преждевременных титров. |
| **CTC Wav2Vec2** | ☑ Включено | Пофонемное кириллическое выравнивание (20 мс) по акустическим формантам голоса. |
| **Сохранять видео** | ☑ По желанию | Использовать оригинальный видеоряд из YouTube клипа в качестве фона караоке. |

## 🤖 MCP Server (Model Context Protocol) & AI Agents

В AI Karaoke Studio встроен официальный **MCP-сервер** (`Model Context Protocol`), позволяющий AI-агентам (**Google Antigravity**, **Claude Desktop**, **Cursor**, **Windsurf**) управлять полным циклом создания караоке.

### Инструменты MCP:
* 🔍 **`list_projects` / `get_project`:** чтение списка проектов, статусов и полной слоговой разметки.
* ⚡ **`generate_karaoke`:** создание нового проекта из файла или YouTube URL с выбором моделей.
* 🔄 **`regenerate_project`:** смена параметров с переиспользованием разделенных стемов из кэша.
* ⏱️ **`shift_line_timing` / `update_project_lyrics`:** пословная и построчная правка таймингов.
* ✂️ **`align_slice`:** хирургическое выравнивание коротких аудио-слайсов.
* 🎬 **`rebuild_video`:** мгновенная пересборка 1080p MP4 с обновлением открытого интерфейса в реальном времени.

#### Подключение к Google Antigravity:
Файл [`.agents/mcp_config.json`](file:///.agents/mcp_config.json) и навык [`.agents/skills/karaoke-automation/SKILL.md`](file:///.agents/skills/karaoke-automation/SKILL.md) уже настроены для автоматической работы.
