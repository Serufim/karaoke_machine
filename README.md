# AI Karaoke Studio 🎤 (v0.5.0)

**AI Karaoke Studio** — это профессиональное автономное приложение для создания караоке-видео студийного качества с полной локальной обработкой нейросетями (разделение вокала Demucs, транскрипция Whisper, побуквенное кириллическое выравнивание Wav2Vec2 CTC, интерактивный 3-дорожечный таймлайн и рендеринг в Full HD 1080p).

Оптимизировано для работы на **Apple Silicon (M1/M2/M3/M4, Metal/MPS)** и **NVIDIA GPU (CUDA)**, а также поддерживает режим процессора (CPU).

---

## ⚡ Быстрый старт и установка

### Вариант 1. Готовые сборки (Релизы)

* 🍏 **macOS:** Скачайте `AI_Karaoke_Studio_macOS.dmg` из [Releases](https://github.com/Serufim/karaoke_machine/releases), откройте и перетащите в папку «Программы» (`Applications`).
* 🪟 **Windows:** Скачайте `AIKaraokeStudio-Setup.exe` (инсталлятор) или `AIKaraokeStudio-Windows-Portable.zip` из [Releases](https://github.com/Serufim/karaoke_machine/releases).

---

### Вариант 2. Запуск из исходного кода (Python 3.11)

Рекомендуемый менеджер окружения — [`uv`](https://astral.sh/uv):

```bash
# Клонирование репозитория
git clone https://github.com/Serufim/karaoke_machine.git
cd karaoke_machine

# Установка зависимостей
uv sync

# Запуск десктопного интерфейса студии (по умолчанию http://127.0.0.1:7860)
uv run python run_ui.py
```

*Для классического интерфейса Gradio:*
```bash
uv run python run_ui.py --gradio
```

### 1. Модели распознавания речи (Whisper)

| Модель | Описание и когда использовать | Ресурсы |
| :--- | :--- | :--- |
| `large-v3-turbo` *(Рекомендуется)* | **Идеальный баланс.** В 4–6 раз быстрее `large-v3`, отлично понимает русский язык, песни, фальцет, оперу и рэп. | ~3–4 ГБ VRAM |
| `bond005/whisper-podlodka-turbo` | Русский fine-tune Whisper Turbo от Ивана Бондаренко. Идеален для русской дикции, сложных рифм и разговорного сленга. | ~3–4 ГБ VRAM |
| `antony66/whisper-large-v3-russian` | Fine-tune на корпусе Common Voice Russian. Прекрасно распознает спокойный эстрадный и бардовский вокал. | ~5–6 ГБ VRAM |
| `large-v3` | Базовая флагманская модель OpenAI с максимальным словарным запасом. | ~6 ГБ VRAM |
| `medium` / `small` | Легкие модели для старых видеокарт или медленных процессоров. | 1.5–2.5 ГБ VRAM |

---

### 2. Модели разделения дорожек (Demucs)

| Модель | Назначение |
| :--- | :--- |
| `htdemucs` | Стандартная быстрая гибридная трансформерная модель. Подходит для чистого звука без сильного перегруза. |
| `htdemucs_ft` *(Рекомендуется)* | **Fine-tuned ансамбль (4x).** Дает кристально чистый вокал без просачивания гитар, синтезаторов и ударных в вокальную дорожку. Обязателен при тяжелом инструментале. |
| `mdx_extra` | Альтернативная модель MDX-Net с усиленной детализацией средних частот. |

---

### 3. VAD-фильтры обнаружения голоса (Voice Activity Detection)

* **`auditok` (Рекомендуется по умолчанию):**
  Энергетический VAD. Анализирует спектральную плотность и амплитуду звука вокала. Отсекает инструментальные соло и длинные паузы, предотвращая преждевременное появление текста до начала пения.
* **`silero`:**
  Нейросетевой классификатор речи. Очень строг к паузам, отлично работает в плотных аранжировках.
* **`none` (Без VAD):**
  Анализируется весь аудиопоток целиком. Рекомендуется только для треков, где вокал звучит непрерывно с 1-й секунды.

---

### 4. Дополнительные переключатели

* **☑ CTC Wav2Vec2 русское выравнивание (`use_ctc_align`):**
  Включает акустическую модель `jonatasgrosman/wav2vec2-large-xlsr-53-russian` с разрешением кадров 20 мс. Модель «примагничивает» буквы и слоги напрямую к звуковым формантам голоса. Первое слово строки попадает ровно в момент открытия рта вокалистом.
* **⬜ Учитывать контекст фраз Whisper (`condition_on_previous_text`):**
  *По умолчанию выключено.* Если включить, Whisper будет учитывать текст предыдущих строк. Для песен это часто приводит к галлюцинациям и зацикливанию одинаковых фраз по кругу. Держите выключенным.
* **⬜ Строгая проверка повторов припевов (`strict_repeats`):**
  Если число повторов куплетов/припевов в предоставленном тексте песни не сходится с аудиозаписью, выравниватель выдаст предупреждение и оставит тайминги чистого распознавания вокала вместо попытки втиснуть лишний текст в пустоту.

## 🎯 Чек-лист: идеальные тайминги для сложных песен

Если песня начинается с длинного инструментального вступления (20–40 секунд) или имеет повторяющийся припев:

1. **VAD:** выберите `auditok`.
2. **CTC Wav2Vec2:** **Включите** галочку.
3. **Demucs:** выберите `htdemucs_ft`.
4. **Контекст Whisper:** держите **выключенным**.
5. **Текст песни:** удалите из текста метки вроде `[Интро]`, `[Куплет 1]`, оставляя только строки, которые реально поются.

## 🔄 Кнопка «Параметры генерации» и быстрая перегенерация

Если результат генерации получился неидеальным, вам **не нужно загружать трек заново и начинать с нуля**:
1. Нажмите кнопку **«Параметры генерации»** в верхней панели студии.
2. Откроется окно со всеми вашими данными:
   - Трек и обложка уже подставлены из проекта;
   - Текст песни находится в поле ввода;
   - Текущие настройки моделей уже выбраны.
3. Поменяйте нужный параметр (например, включите `CTC Wav2Vec2` или отредактируйте строку текста) и нажмите **«Перегенерировать трек»**.
4. **Умный кэш:** если модель Demucs не менялась, разделение стемов берется из кэша — перегенерация перезапустит только распознавание и займет считанные секунды!

## 🎬 Спецификации экспорта и видео

* **Разрешение:** Full HD (1920×1080), 30 fps, соотношение сторон 16:9.
* **Кодеки:** H.264 (аппаратное ускорение VideoToolbox на macOS, NVENC на NVIDIA, либо libx264 на CPU) + AAC Stereo.
* **Телесуфлер:** 3 или 4 строки на экране с отсчетом `● ● ●` за 3 секунды до вступления.
* **Dual-Audio MP4:** дорожка 1 — чистый минус (для исполнения), дорожка 2 — оригинальный трек (для диджея или подсказки).
* **Стили подсветки:** Cyberpunk, Gold Neon, Studio Silver, Ambilight edge-glow по цветам обложки трека.
